## CSM 1.2.12

### 🐞 问题修复

- **Windows 上内容相同的表不再被误判为「有差异」**：
  - Windows 版 Excel 保存单元格里的换行时用的是 `\r\n`，云端表格导出只有 `\n`，以前比较时会把这两种换行当成不同，差异预览里出现一串 `␍` 标记；
  - 现在比较时把 `\r\n`、`\r` 与 `\n` 视为同一种换行，这类表会正确显示为已同步 / 无差异；
  - 差异预览里编辑后重新计算差异也按同样规则处理；
  - 升级后旧的核对结果会自动作废并重新核对，无需手动刷新；
  - 只改判断规则，上传 / 下载时单元格内容原样保留。
