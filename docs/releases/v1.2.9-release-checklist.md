## B. ⚠ 自动检查命中、需人工确认的遗留项

- [ ] **B1. 强制覆盖对源表公式的破坏性确认** — 负责人：维护者 / 程序
  - 命中判据：强制上传覆盖允许覆盖源表中的非 spill 公式（如 `=GOOGLETRANSLATE` 机翻公式）。该设计是为支持人工精修翻译替换机翻，但若业务源表中存在重要的业务计算公式（如复合求和、加权规则），强制覆盖会将其替换为静态值。需确认用户了解此行为。
- [ ] **B2. Windows 包交叉打包验证** — 负责人：维护者 / QA
  - 命中判据：Windows 安装包在 macOS 环境下由 electron-builder 交叉编译生成，发布前建议在 Windows 实机启动测试安装。
