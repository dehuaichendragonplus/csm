## CSM 1.2.11

### ✨ 新增功能与体验优化

- **老项目一键接入，不再需要先手写配置**：
  - 选中的目录里既没有 `syncmanager.config.json` 也没有 `filelist.json`、但有 xlsx 配置表时，添加项目弹窗会显示找到的表数量，按钮变为【生成配置并添加】，点击即自动生成 `filelist.json` 与 `syncmanager.config.json`；
  - 自动从附近的导表脚本（如 `ExcelTools/bc*.sh`）里识别「本地 xlsx ↔ 云端表格」的对应关系并预填进清单，注释行、带变量的路径、目录外的表都会跳过；
  - 没识别到云端链接的 xlsx 可在「管理配置表」里绑定或上传；
  - 项目名自动跳过 `Configs`、`Res` 等通用目录名（如 `SmashBlast1/Res/Configs` → `SmashBlast1`）；
  - 「项目设置 → 更改目录…」选到老项目目录时同样适用。
- **云端表没有访问权限时直接说明原因**：
  - 以前一律显示「错误: not_found」，现在能区分「表存在但当前账号没权限」和「表不存在 / 链接有误」；
  - 没权限的表状态显示【无权限】，并提示点云端表名旁的 ↗ 打开表格申请访问权限，拿到权限后点「重新检查」即可；
  - 其他云端查询错误也改为中文说明。
- **新增《新手使用指南》**：`docs/新手使用指南.md`，一页看懂安装、登录、添加项目和日常同步。
