## CSM 1.2.5

### 🐞 修复：上传后差异预览 / 核对 / 下载可能还在用旧的云端内容

CSM 会把云端表的导出结果缓存在本机，并用云端的「修改时间」区分版本。1.2.4 新增的「写回源表」改的是源表，镜像表（`IMPORTRANGE`）的内容虽然变了，修改时间却不会变，于是：

- 差异预览、内容核对会继续拿上传前的旧内容比较，可能误报差异；
- 若此时对该表点「下载」，可能把旧内容写回本地，丢掉刚上传的改动。

从 1.2.5 起，上传成功后会立即清掉这张表的导出缓存与核对结果，下一次差异预览 / 核对 / 下载都会重新从云端导出。

> 已用 1.2.4 对含公式的表做过「写回源表」上传的同学：升级后重启一次 CSM 即可，旧缓存会在下次上传时自动清理；如需立即刷新，可在差异预览里点「刷新」强制重新比较。

### ⚠ 已知限制（将在下一版修复）

镜像表（`IMPORTRANGE`）的修改时间不随源表变化，因此**别人改了源表后，1.2.5 不会把镜像表标为「有更新」**。在下一版修复之前，拉取这类表前请在差异预览中强制刷新，或直接核对源表。

下一版起，CSM 会识别镜像表的源表，按「镜像表与各源表中最新的修改时间」判断是否有更新；源表无权限或查询失败时会在列表里提示「无法检查源表更新」。
