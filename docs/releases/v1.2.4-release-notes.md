## CSM 1.2.4

### 🛡 上传不再冲掉云端公式

以前「上传」会用本地 xlsx 整表替换云端表。本地 xlsx 里只有值、没有公式，所以云端的公式（例如 `IMPORTRANGE` 镜像主表、`VLOOKUP`）会被永久替换成死值，镜像关系就此断开。

从 1.2.4 起：

- **云端没有公式的表**：和以前一样整表替换，使用方式不变。
- **云端有公式的表**：改为按单元格写入，**公式原样保留**。
  - 非公式区：本地与云端不同的格直接写入。
  - `IMPORTRANGE` 镜像区：镜像区本身写不进值（会把公式顶成 `#REF!`），所以按公式把改动**写回它的源表**，镜像随之自动更新，最终云端与本地完全一致。
  - `VLOOKUP` 等公式算出来的格：不写，源数据更新后自动跟着变。
- **写源表前会弹窗确认**：列出要写的源表、每张表的格数和示例；取消则什么都不写。
- **安全核对**：源格本身是公式、源格刚被别人改过（与镜像看到的不一致）、超出公式引用范围、多张镜像表要写同一源格但值不同、镜像公式当前报错（如 `IMPORTRANGE` 未授权）——这些格一律不写，并在日志逐条列出，该表不会被记为「已同步」。
- 新增配置项 `preserveCloudFormulas`（默认开启）；设为 `false` 可退回旧的整表替换。

> 升级前的旧版本 CSM 请勿再对含公式的云端表点「上传」。
