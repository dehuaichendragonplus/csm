## B. ⚠ 自动检查命中、需人工确认的遗留项

- [ ] **B1. Windows 包未在实机验证** — 负责人：维护者 / QA
  - 命中判据：Windows 安装包由 macOS 交叉打包生成，本机无法运行验证。
  - 为什么我不下结论：交叉打包成功只说明产物生成了，不代表在 Windows 上能装、能启动。
- [ ] **B2. 老项目脚本识别只在 SmashBlast1 一种脚本格式上实测过** — 负责人：维护者 / 程序
  - 命中判据：识别规则是「同一行同时出现 spreadsheetId（或表格链接）和 xlsx 路径」，只用 SmashBlast1 的 `ExcelTools/bc*.sh` 实测（9 / 9 识别）。
  - 为什么我不下结论：其他老项目的导表脚本写法未知，可能出现漏识别或误配，需要接入时看一眼生成的 `filelist.json`。
- [ ] **B3. 「无权限」判定依赖 Google Sheets API 已启用** — 负责人：维护者
  - 命中判据：Drive 返回 404 后会再调 Sheets API 区分原因；本机用真实账号实测正常（SmashBlast1 两张表 → 无权限，伪造 ID → 不存在）。
  - 为什么我不下结论：若 OAuth 客户端所在 GCP 项目关闭了 Sheets API，会退回显示「找不到云端表」，不会误判，但提示就不够准确。
