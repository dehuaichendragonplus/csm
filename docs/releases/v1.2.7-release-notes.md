## CSM 1.2.7

### ✨ 差异预览改为 Beyond Compare 风格，能直接在里面编辑

**看差异**：配色和说法照 Beyond Compare，不再按同步方向说「新增 / 删除」。

- **红色**：两边不同的行，不同的单元格加深、红字
- **紫色**：只有一侧有的行（孤立行），另一侧画紫色斜纹
- **黄色**：已经编辑、还没保存的内容
- 顶部汇总和左侧工作表列表改为「差异 N 行 · 仅本地 N 行 · 仅云端 N 行」，编辑后实时刷新

**编辑（「并排」模式）**：

- 选择：拖动框选单元格范围；点行号选整行；按住 Shift 扩展选择。两侧同步高亮
- 复制到另一侧：工具栏「复制到右侧 → / ← 复制到左侧」、右键菜单、每个有差异的行前的小箭头，或 ⌥→ / ⌥←
- 只在一侧有的行：复制过去就在另一侧插入整行；从空的一侧复制过去就删掉这一行
- 撤销：⌘Z（Windows 为 Ctrl+Z）或工具栏「撤销」

**保存**：两侧分别保存。

- **保存本地**：写回本地 xlsx，保存前自动备份（可在「本地备份」恢复）。样式、列宽、其他工作表保持不变，文本型数字（如 `"1"`、`"1,13"`）保持文本
- **保存到云端**：沿用上传逻辑，有公式的表只写改过的单元格，需要写回源表时会先确认
- 保存后两边内容一致时，自动记为「已同步」

**保护措施**：

- 打开差异窗口之后本地或云端又被改过，保存会被拒绝，请重新比较
- 发现 xlsx 正被 Excel / WPS 打开时先提醒，避免那边再保存把这里的修改冲掉
- 有合并单元格的表不能插入 / 删除行（合并区域会错位），只能改单元格
- 有未保存的编辑时，关闭窗口或整表覆盖前会先确认
- 表太大（视图被折叠 / 截断）或按业务 ID 查找时只能查看，不能编辑

### 🐞 修复

- 并排模式拖动横向滑块时，两侧滚动互相拉扯导致画面闪动、两侧位置对不齐
- 并排模式折叠行的提示文字开头被遮住
