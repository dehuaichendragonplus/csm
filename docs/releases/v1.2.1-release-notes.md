## CSM 1.2.1

### 🐛 修复
- **首次安装直接跳转浏览器完成 Google 授权**：安装包重新内置 OAuth 客户端凭证，不再弹出「请选择 credentials.json」窗口（1.2.0 的问题）

### ⚠ 升级须知
- **已安装 1.2.0 并卡在「选择 credentials.json」窗口的**：直接下载本版本覆盖安装即可，不需要再找凭证文件
- 已安装 1.2.0 且能正常使用的：在 App 顶栏点「更新」，或在「全局偏好设置 → 关于 CSM」里检查更新
- 安装包未签名：
  - macOS 首次打开请在「应用程序」中**右键 CSM → 打开**
  - Windows 出现 SmartScreen 提示时点「更多信息 → 仍要运行」
