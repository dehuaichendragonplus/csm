## CSM 1.2.0

### ✨ 新功能
- **应用内自动更新**：启动后及每 6 小时自动检查 GitHub 新版本；顶栏出现「更新」按钮与红点，「全局偏好设置 → 关于 CSM」可手动检查更新、查看更新说明与下载进度
  - Windows：应用内下载安装包，完成后「重启并覆盖安装」
  - macOS：自动下载 Apple 芯片版 dmg 到「下载」目录，打开后拖入「应用程序」覆盖
- **新增安装包**：Windows x64 安装包（macOS 只提供 Apple 芯片版本）
- **文档收藏**：顶栏全局「文档收藏」，支持跨项目快速打开在线文档、分组折叠、网页图标
- **界面全面升级**：Chrome 风格标签栏与工具栏、配置表列表改为表格布局、全局设置与项目设置拆分（⌘, / ⌘;）
- 双击标签页重命名项目、拖动调整项目标签顺序
- 云端修改人直接显示、常用表星标收藏、Luban 报错诊断卡片、Luban 导出按钮前置
- Dock 角标、系统横幅通知、项目标签角标
- 全局偏好设置支持「退出登录」

### ⚡ 改进
- 内容核对提速；没有同步记录但内容一致的表自动标为已同步；新增「需核对表全部下载」
- 云端导出缓存与差异比对性能优化，差异预览滚动条与滑块显示优化
- 主列表副行显示业务备注，表名悬停显示本地路径

### 🐛 修复
- 本地文件重新保存但内容未变时不再误判为本地变更
- 修复 Google Drive 批量查询时他人修改人丢失
- 修复点击刷新时内容核对被缓存阻断
- 修复点击当前标签导致双击失效、文档管理器所属项目下拉为空等问题

### ⚠ 升级须知
- **安装包不再内置 Google OAuth 凭证**：升级后首次启动会提示选择一次 `credentials.json`（向维护者或团队 wiki 获取），之后保存在本机，不再询问
- **从 1.1.3 升级需要手动下载安装一次**；从 1.2.0 起之后的版本都可以在 App 内更新
- 安装包未签名：
  - macOS 首次打开请在「应用程序」中**右键 CSM → 打开**
  - Windows 出现 SmartScreen 提示时点「更多信息 → 仍要运行」
