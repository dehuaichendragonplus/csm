## CSM 1.2.3

### ✨ 新增功能与改进

- **macOS 双架构支持（Intel + Apple Silicon）**：
  - 重新恢复并支持导出 macOS Intel 芯片（x64）安装包，现同时提供 Apple 芯片（arm64）与 Intel 芯片（x64）双架构 `.dmg` 安装包，全面兼容所有型号 Mac。
  - 应用内更新机制已原生适配双架构自动识别与下载。
- **工具栏响应式自适应布局**：
  - 工具栏增加容器查询（Container Queries）与媒体查询自适应机制。在窗口宽度较窄（≤ 1280px）时，「管理配置表」「操作历史」「项目设置」自动收折为紧凑的图标按钮（悬停保留完整功能说明），优先确保项目导出按钮群完整展示，杜绝按钮被挤压截断。
  - 非 Luban 项目体验优化：对于未配置 Luban 的项目，自动隐藏置灰无效的「Luban导出」按钮，释放更多可用操作空间。
