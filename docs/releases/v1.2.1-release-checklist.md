## B. ⚠ 自动检查命中、需人工确认的遗留项

- [ ] **B1. `client_secret` 随安装包公开**（这是有意的决定）— 负责人：维护者
  - 命中判据：两个安装包里都有 `credentials.json`，和仓库本地文件逐字节一致；Release 是公开的。
  - 这是 Google「桌面应用」类型的 OAuth 客户端，Google 官方说明这类 secret 本就无法保密。**请在 Google Cloud Console 确认 OAuth 同意屏幕的用户类型是「内部」**：是「内部」的话只有公司 Google 账号能授权；如果是「外部」，任何人都能拿这个客户端发起授权请求。
  - 为什么我不下结论：我没有这个 Google Cloud 项目的访问权限，看不到同意屏幕的设置。

- [ ] **B2. 卡在 1.2.0 选择凭证窗口的人没法用应用内更新** — 负责人：维护者
  - 这些人打不开 App 主界面，要手动下载 1.2.1 覆盖安装（或者先选一次凭证文件进入 App，再在 App 内更新）。发布通知里需要写明。

- [ ] **B3. 1.2.0 → 1.2.1 是第一次真正走应用内更新** — 负责人：QA
  - Windows 的「下载 → 重启并覆盖安装」、macOS 的「下载 dmg → 打开」都是第一次在真实 Release 上跑，建议各找一台已装 1.2.0 的机器实测。
