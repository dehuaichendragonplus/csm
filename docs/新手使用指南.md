# CSM 新手使用指南

> **CSM 是干什么的？**
> 配置表放在 Google 表格（云端）上，项目里用的是本地 xlsx。
> CSM 帮你看清**哪些表两边不一样**，一键**下载**到本地，或把本地改动**上传**回云端。

---

## 一、安装（只做一次）

1. 从维护者给的地址（GitHub Release）下载安装包：
   - Mac（M 系列芯片）：`CSM-版本号-mac-arm64.dmg`
   - Windows：`CSM-Setup-版本号-x64.exe`
2. **Mac**：把 CSM 拖进「应用程序」。第一次打开要**右键 → 打开 → 打开**（直接双击会被系统拦住）。
   如果提示「已损坏，无法打开」，打开「终端」粘贴下面这行回车，再打开就行：

   ```bash
   xattr -dr com.apple.quarantine "/Applications/CSM.app"
   ```

3. **Windows**：双击安装包，一路下一步。

## 二、登录 Google（只做一次）

1. 打开 CSM，点 **「前往授权」**。
2. 浏览器会弹出 Google 登录页，用**公司 Google 账号**登录，点「允许」。
3. 回到 CSM，页面会自动刷新。

> 登不上？找维护者确认你的账号已加进白名单。

## 三、添加你的项目（只做一次）

1. 点顶部标签栏的 **「＋」**（添加新项目）。
2. 在弹窗里一层层点进去，找到项目的**配置表目录**——带 **★** 的那个就是。
3. 点 **「添加此目录」**。

完成后，所有配置表会按状态分组列出来。

---

## 四、日常使用：只看颜色，只点一个按钮

每张表右边**最多只有一个按钮**，它告诉你该做什么：

| 状态 | 意思 | 你要做的 |
|---|---|---|
| ● **已同步** | 两边一样 | 什么都不用做 |
| ⚡ **有更新** | 别人改了云端 | 点 **下载** |
| ⊘ **本地缺失** | 本地还没有这张表 | 点 **下载** |
| ⟲ **本地变更** | 你改了本地 | 点 **上传**（会先给你看差异） |
| ⚠ **冲突** | 两边都改了 | 点 **解决冲突**，看差异后选保留哪边 |

### 最常用的三个动作

- **一次性拉最新**：点右上角 **「下载项目更新」**，所有「有更新 / 本地缺失」的表一起下载。
  （冲突和本地改过的表不会被动，放心点。）
- **看看改了什么**：点行右侧的 **⇄**，左右对照、改动的格子会高亮。
- **刷新状态**：点左上角的 **刷新** 按钮（或按 `⌘R`）。

### 找表

按 `⌘F`（或直接按 `/`），输入表名、路径或备注里的任意关键词即可。

---

## 五、不用怕改坏

- **下载前会自动备份**本地文件。下错了？点该行的 **🕘** → 选一份 → **恢复**。
- **上传前一定先给你看差异**，确认后才会覆盖云端。
- **上传时如果别人刚好也改了云端**，CSM 会拦下来并告诉你是谁改的，不会悄悄覆盖。
- 云端被覆盖了也能找回：在 Google 表格里「文件 → 版本历史」。

## 六、遇到问题

| 现象 | 怎么办 |
|---|---|
| 某张表显示「错误: forbidden」 | 你没有这张表的权限，找表格负责人共享给你 |
| 上传提示权限不足 | 点右上角头像（全局偏好设置）→ **重新授权** |
| 状态看着不对 | 点 **项目设置** →「清除同步缓存」旁的 **清除缓存**，再刷新（不会删本地文件） |
| 项目目录搬家了 | **项目设置** → **更改目录…**，重新选一下 |

---

**就这些。记住一句话：看状态颜色，点那一行唯一的按钮。**

更多高级功能（自定义动作、云端目录映射、配置表清单编辑等）见项目根目录的 `README.md`。
